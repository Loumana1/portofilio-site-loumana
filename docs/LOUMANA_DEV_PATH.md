## Projects

### Finished enough to ship or to hand in

**808 MAX** — `Documents/Coding/808 Max VST Plugin`  
A sample instrument for 808 bass: saturation, envelope, filter, waveform, reverse. VST3, AU, and standalone. Built in HISE. License GPL-3. The repo README still says public installers are not published yet. He counts the instrument as finished, and does not want it described as a C++ career. A visual preset browser is a separate UI experiment, not the finished instrument. Other HISE folders exist beside it (`HISE PROJECTS`: Moo_bass, Monolights, Bass_sample_library, training scripts). Those are studies and side instruments, not 808 MAX.

**Snap to Grid** — https://snaptogrid.org — 2026, independent, in production on a VPS  
Web step sequencer. Create, share, and export MIDI. PHP, JavaScript, MySQL, Slim 4, JWT, OAuth (Google), PHPUnit, Playwright, GitHub Actions. Integrations: Spotify, Discogs, YouTube, MusicBrainz. Working copy: `Documents/Coding/Snap the grid (step by step)`.

**EPayFC** — EPFC, course PRWB, 2025–2026

### In progress

**Micro-opacités** — `Documents/Coding/memoires-en-transit`  
The installation’s name. The docs also carry the longer title Mémoires en transit. Generative piece for 8 speakers. Sound: Simon Mahungu. Pure Data: Alassane Traoré. Python writes the patches and, for the Brussels version, the scores. It runs on a Raspberry Pi. Three zones in the Brussels version: Cortex, Hippocampe, Reconstruction. A bed plays on all 8 speakers the whole time. Fragments move over it. One cycle is 90 seconds.
